## ✨ Features

- 🎨 **Sonic Glass Aesthetic** - Futuristic dark obsidian (#07070d) glassmorphism, electric violet (#8b5cf6), and hyper pink (#ec4899) dynamic lighting.
- 🌓 **Adaptive Theming** - Light, Dark, and System modes with fluid aurora ambient backgrounds.
- 🎵 **Acoustic Visualizer & Vinyl Disc** - High-framerate audio spectrum, circular visualizer, and authentic vinyl textures.
- 📱 **Multi-Device Responsive** - Desktop squircle master layout and mobile bottom floating pill TabBar navigation.
- ☁️ **Cloud Gateway** - Cloudflare Edge Functions + Epomail OAuth ecosystem integration.
